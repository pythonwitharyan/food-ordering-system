# 🍔 Food Ordering System

## 📌 Project Description

The **Food Ordering System** is a simple beginner-level Python project that allows users to view a food menu, select food items, enter quantities, and calculate the total bill.

This project is created using **basic Python concepts up to functions**.

## 🎯 Objectives

- Display a food menu
- Allow users to select food items
- Take the quantity of food items
- Calculate the total bill
- Display the final amount
- Understand the use of Python functions

## 🛠️ Technologies Used

- Python
- Variables
- User Input
- `if-elif-else`
- Loops
- Functions
- Arithmetic Operations

## ⚙️ Workflow

**Start**  
↓  
**Display Food Menu**  
↓  
**Select Food Item**  
↓  
**Enter Quantity**  
↓  
**Calculate Item Price**  
↓  
**Add Price to Total Bill**  
↓  
**Order More?**  
↓  
**Yes → Select Another Item**  
↓  
**No → Generate Final Bill**  
↓  
**Display Total Amount**  
↓  
**End**

## 🧩 Functions Used

### `show_menu()`

Used to display the available food items and their prices.

### `calculate_bill()`

Used to calculate the price of the selected food item according to the quantity.

### `main()`

Used to control the complete flow of the food ordering system, including menu display, user input, ordering, and final bill generation.

## 🔄 Function Workflow

`main()`  
↓  
`show_menu()`  
↓  
**User Selects Food**  
↓  
`calculate_bill()`  
↓  
**Update Total Bill**  
↓  
**Order More?**  
↓  
**Yes → Repeat**  
↓  
**No → Display Final Bill**
